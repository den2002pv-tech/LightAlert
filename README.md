# LightAlert

LightAlert — нативное Android-приложение для получения расписаний плановых и аварийных отключений электроэнергии из выбранных Telegram-каналов.

## Технологии

- Kotlin, Jetpack Compose и Material 3
- MVVM, Coroutines и Flow
- Room — история сообщений, ревизий и эффективных очередей
- Preferences DataStore — локальные настройки
- TDLib — подключение к Telegram непосредственно на устройстве
- Минимальная версия Android: 8.0 (API 26)

## Telegram / TDLib

В проект добавлена TDLib Android distribution `io.github.tdlib-android:core:0.1.1`, опубликованная в Maven Central. Это сторонняя сборка TDLib, а не официальный бинарный релиз Telegram; версия закреплена явно, чтобы обновления не меняли API неожиданно. Используется низкоуровневый Java Client, а не KTX-обёртка: KTX-обёртка этой версии передавала пустой ключ базы данных. Перед выпуском приложения нужно отдельно проверить обновления, контрольные суммы и лицензии используемых компонентов.

Сборка APK ограничена ARM ABI (`arm64-v8a`, `armeabi-v7a`), чтобы не включать в APK библиотеки эмуляторов x86.

### Локальная конфигурация

1. Получите Telegram API ID и API Hash в [Telegram API tools](https://my.telegram.org/apps).
2. Добавьте значения в корневой `local.properties` (этот файл уже исключён из Git):

```properties
TELEGRAM_API_ID=123456
TELEGRAM_API_HASH=your_api_hash
```

Также поддерживаются переменные окружения и Gradle project properties с теми же именами. Не добавляйте реальные значения в Git, issue, логи CI или сообщения.

API ID и API Hash попадают в BuildConfig собранного приложения, поэтому их нельзя считать секретами уровня пароля. Код входа, пароль двухэтапной проверки и пользовательская сессия не должны попадать в исходники или логи.

## Обработка расписаний

`ScheduleMessageIngestionService` нормализует входящие сообщения, распознаёт расписания, дедуплицирует повторные версии, сохраняет историю и атомарно применяет частичные обновления. Отсутствующие в новом сообщении очереди не затираются.

## Сборка и тесты

Требуется JDK 17 или совместимая более новая версия.

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions выполняет unit-тесты и сборку Debug APK для веток `main` и `feature/android-foundation`, а также публикует APK как artifact на 14 дней.
